#Projeto Cadastro

Este é um projeto simples de cadastro de usuários, feito em Python.

## Funcionalidades
- Permite criar novos usuários
- Valida e-mails e senhas
- Armazena os dados dos usuários

## Como usar
1. Baixe o projeto
2. Execute o arquivo principal (ex: `main.py` ou `index.html`)
3. Siga as instruções na tela

- Python
